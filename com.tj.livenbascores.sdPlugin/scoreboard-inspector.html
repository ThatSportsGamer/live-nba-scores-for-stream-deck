Handy for telling boards apart, like an NBA board and a G League board on the same page. Lighter or brighter colors can make the white text harder to read.
How it works:
• Place this action on as many keys as you want — each key is one game
• Shows today's games in tip-off order; the day moves on at 2:00 AM. No games today? It shows the next game day's schedule
• Lead changes and ties flash in the team's color, then a card (NY / UP 3, TIED / 88-88); the clock turns red in the last 2:00 of the 4th and overtime
• Keys refresh every 30 seconds (every 15 in crunch time)
• Press any key to open that game in ESPN Gamecast (the box score once it's final)
• Changes here apply to this whole board: the block of Scoreboard keys this key is part of
More than one board: each key remembers its own settings, so an NBA page and a G League page work, and boards can share a page too; give each its own background color to tell them apart. New Scoreboard keys start on the NBA. Each Stream Deck you use gets its own board.
